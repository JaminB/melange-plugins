# Sunstone

A client-only graphics overhaul for Worms Ultimate Mayhem, built from Mirage and the engine's own switches.
Shaders, code and original or permissively licensed art only — no game texture, or anything derived from one, is
ever shipped.

## Quality and look

A **Quality** setting (Off / Low / Medium / High) on the Mods page turns Sunstone's effects on together with
sensible parameters; a **Look** setting (Golden / Dusk) picks which of the two colour-grading LUTs the Grade
effect leans toward. Both apply live, no restart. Every effect still has its own toggle and parameters in the
overlay's *Mirage/Post-FX* panel (and in `Melange.ini [MiragePostFX]`) if you want to go off the preset — a manual
change there survives until you next change Quality.

| Quality | Effects on | Notes |
|---|---|---|
| Off | none | vanilla rendering |
| Low | SMAA, Sharpen, Sky glow, Fog, Grade | cheap: AA, sharpen and world grade only |
| Medium (default) | + SSAO (8 taps), Bloom | |
| High | SSAO at 16 taps/larger radius, stronger bloom/grade | |

Expected GPU cost at 1080p, from development profiling of equivalent techniques: SMAA + CAS + bloom + tonemap +
SSAO together measured **0.36 ms**, against a design budget of **0.6 ms for L2** (grade/AA) and **1.2 ms for L3**
(atmosphere). Re-measure with Melange's GPU timers (*Mirage/GL* overlay, or `gltrace.gpu`) before calling a preset
final on a given machine; High is comfortably inside budget on an RX 7800 XT.

## L0/L1 recap (framework)

- **GPU timer queries** (swap-to-swap and per Mirage stage) in the *Mirage/GL* overlay panel, and a runtime
  enable/disable per mod GLSL program in *Mirage/Shaders* — both Melange framework features this plugin relies on
  but does not ship.
- **Texture clarity**: 16x anisotropic filtering and trilinear minification filtering on the game's own textures,
  declared in `mod/spice.json`'s `graphics` block and applied by Melange's `MirageTextures` component. Off
  (vanilla) unless this mod is enabled or `Melange.ini`'s `[MirageTextures]` overrides it:

  ```ini
  [MirageTextures]
  Anisotropy=auto   ; auto | an integer 0-16
  Trilinear=auto    ; auto | on | off
  LodBias=auto      ; auto | a number from -8 to 8
  ```

## L2 — Grade and anti-aliasing

Post-FX effects under `mod/postfx/`, all off by default until Quality turns them on:

- **`smaa`** (Final): SMAA 1x anti-aliasing ([iryoku/smaa](https://github.com/iryoku/smaa), MIT — `LICENSE.txt` in
  the folder). Use instead of the game's `/FXAA`, not with it.
- **`sharpen`** (Final): AMD FidelityFX Contrast Adaptive Sharpening, no upscale
  ([FidelityFX-CAS](https://github.com/GPUOpen-Effects/FidelityFX-CAS), MIT — `LICENSE.txt` in the folder).
- **`grade`** (PostWorld, so the HUD is never tinted): a filmic curve, exposure/contrast/saturation, a blend
  between two colour-grading LUTs (`golden.png`, `dusk.png`, both generated by `tools/make_luts.py` from an ASC
  CDL transform — pure code, never sampled from a game frame), a radial vignette and fine grain.

## L3 — Atmosphere

- **`ssao`** (PostWorld): ambient occlusion from the depth buffer, rewritten from the mirage-samples scout sample
  to fix its sky artefacts — a hard sky mask ahead of any sampling, a view-distance falloff, edge-aware normals
  that drop a neighbour rather than reach across the horizon, and a bilateral blur that never blends a sky texel
  into a ground one.
- **`sky`** (PostWorld): an analytic gradient and sun glow/disc over the game's own sky dome (the dome texture is
  never replaced or sampled into anything shipped — only tinted and added to).
- **`fog`** (PostWorld): height and distance fog with sun-tinted in-scatter, matched in tone to the sky gradient;
  skips sky pixels, so it never double-fogs the horizon the sky effect already paints.
- **`bloom`** (PostWorld): a soft-knee bright-pass and separable blur, combined in approximately linear light.

## Client-only

`"kind": "client-only"` in `spice.json`. Mirage only touches GL state and shaders; no sim data, Tweak or
CRC-listed file is touched by any of the above.

## What's next

Shadows, lighting, water and supersampling each need framework work in Melange first, and will ship in later
releases.
